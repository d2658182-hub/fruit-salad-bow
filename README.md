# Fruit Salad Bow

2D archery fruit-shooting game (HTML5 / CreateJS + Howler). Shoot the bow to slice fruits and hit targets without missing.

## Controls

**Desktop**
- **Mouse drag + release** : aim and shoot (hold left button, drag to set angle/power, release)
- **Mouse** : navigate menus (Play, Restart)

**Mobile / Tablet (Touch)**
- **Swipe + release** : aim and shoot (drag finger to aim, lift to fire)
- **Tap** : menu buttons

No keyboard required. Play in portrait or landscape — canvas auto-scales.
